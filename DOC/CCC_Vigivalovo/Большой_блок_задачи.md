# Большой блок задачи

Родительский документ: `Правила_запуска_задач`.

Служебная подпись находится снаружи и не входит в копируемый текст. После неё компактная постановка уникальной работы выдаётся одним непрерывным кодовым блоком. Постоянные правила не копируются: TASK ссылается на их канонических владельцев.

**БЛОК 1 — БОЛЬШАЯ ЗАДАЧА**

```text
# ЗАДАЧА — НАЗВАНИЕ

Режим: Ограниченный / Самостоятельный

## Цель

Описать проверяемый результат.

## Специфический контекст

Указать проект, исходное состояние и важные ограничения.

## Разрешённый scope

Перечислить разрешённые файлы и действия.

## Нестандартные запреты и особые разрешения

Перечислить запрещённые файлы, действия и Git-операции.

## Обязательные проверки

Перечислить проверки результата и неизменности запрещённых областей.

## Критерии готовности

Описать одновременно необходимые условия завершения.

## Дополнения к стандартному отчёту

Указать только поля сверх формы `Отчёт_агента` либо написать `нет`.

## Применяемые правила

Сослаться на `Правила_агентского_цикла`, `Правила_запуска_задач` и необходимые тематические правила.
```

После публикации TASK замораживается. Для запуска Ассистент обязательно выдаёт отдельный [[Малый_блок_задачи|малый стартовый блок]].
