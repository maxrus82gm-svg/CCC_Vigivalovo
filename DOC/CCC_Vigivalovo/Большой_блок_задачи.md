# Большой блок задачи

[[Старт]] · [[Задача_агенту]] · [[Малый_блок_задачи]]

Полная постановка задачи выдаётся одним непрерывным кодовым блоком.

```text
# ЗАДАЧА — НАЗВАНИЕ

Статус: новая активная задача.

## Цель

Описать проверяемый результат.

## Контекст

Указать проект, исходное состояние и важные ограничения.

## Разрешённый scope

Перечислить разрешённые файлы и действия.

## Запрещённый scope

Перечислить запрещённые файлы, действия и Git-операции.

## Порядок выполнения

Задать последовательность чтения, изменений и проверок.

## Обязательные проверки

Перечислить проверки результата и неизменности запрещённых областей.

## Критерии готовности

Описать одновременно необходимые условия завершения.

## Формат итогового отчёта

Указать обязательные поля отчёта и место записи.

## Политика Git

Указать явно; отсутствие разрешения не означает разрешение на Git.
```
