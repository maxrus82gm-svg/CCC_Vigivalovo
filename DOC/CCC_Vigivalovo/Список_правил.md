# Список правил

Этот документ — дочерняя служебная матрица `Карты агентской документации`. Он поясняет распределение ответственности, не заменяет карту и намеренно не создаёт повторный набор wiki-связей.

| Область | Канонический владелец |
|---|---|
| Роли, режимы, заморозка TASK, жизненный цикл и REVIEW | `Правила_агентского_цикла` |
| Выбор большой или малой задачи, внешние подписи блоков, запуск, уточнения и БЛОКИ 1–3 | `Правила_запуска_задач` |
| Git, обязательная удалённая проверка после отчёта, свежий SHA и REVIEW | `Правила_Git_и_проверки` |
| Локальный режим агента и разрешение на внешний доступ | `Правила_локальной_работы_агента` |
| Markdown, UTF-8, кириллица, frontmatter, wiki-links | `Правила_создания_документов` |
| Решение о делегировании и контроль результата | `Правила_использования_субагентов` |
| Профили, маршруты и permissions | `Настройка_прав_субагентов` |
| Активная TASK, последний отчёт и последний статус | `Задача_агенту` |
| Подготовка внешней задачи | `Задача_внешнему_субагенту` |
| Формы отчётов | `Отчёт_агента`, `Отчёт_субагента`, `Отчёт_проверки` |
| Формы постановки задач | `Большой_блок_задачи`, `Малый_блок_задачи` |

Обязательный минимум определён в `Старт`. Переход к нужному владельцу выполняется через `Карта_агентской_документации`.
