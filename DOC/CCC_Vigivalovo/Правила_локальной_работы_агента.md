# Правила локальной работы агента

[[Старт]] · [[Список_правил]] · [[Правила_Git_и_проверки]] · [[Правила_использования_субагентов]]

## Режим по умолчанию

Основной агент Codex, работающий в локальной среде проекта, и запускаемые им локальные субагенты работают только с локальными файлами, каталогами, процессами и инструментами.

Если пользователь не дал чёткого прямого указания на внешний доступ, запрещено:

- обращаться к интернету, сайтам и внешним API;
- использовать облачные сервисы, приложения-коннекторы, электронную почту и мессенджеры;
- читать или изменять удалённые репозитории, выполнять `fetch`, `pull`, `push` и другие сетевые операции Git;
- передавать локальные файлы, их содержимое или сведения о проекте во внешние системы;
- запускать внешнего агента или передавать ему задачу.

Наличие URL в документе, доступного сетевого инструмента, активного подключения или сохранённой авторизации не является разрешением на внешний доступ.

## Прямое указание пользователя

Внешний доступ разрешён только после чёткого прямого указания пользователя. Такое указание действует исключительно для названного ресурса, действия и текущей задачи и не меняет локальный режим по умолчанию для последующей работы.

Если для выполнения задачи действительно нужен внешний ресурс, но прямого указания нет, агент останавливает внешнее действие и запрашивает разрешение, называя ресурс и цель обращения.

## Локальные действия

В рамках явно поставленной задачи разрешены локальное чтение, поиск, анализ, редактирование, сборка и проверки только в допустимом scope.

Работа с локальным состоянием Git дополнительно ограничена правилами [[Правила_Git_и_проверки]]. Это правило не расширяет разрешения на Git, служебные каталоги, код, ассеты, конфигурацию или сборочные настройки.
