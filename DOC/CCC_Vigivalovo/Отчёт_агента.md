# Отчёт агента

[[Карта_агентской_документации]] · [[Правила_агентского_цикла]] · [[Задача_агенту]]

Единый стандартный формат отчёта. TASK добавляет только специальные поля, действительно нужные конкретной работе.

```text
ОТЧЁТ АГЕНТА

TASK:
- название

РЕЖИМ:
- Ограниченный / Самостоятельный

СТЕПЕНЬ ВЫПОЛНЕНИЯ:
- выполнено полностью / выполнено частично / не выполнено

ИЗМЕНЕНО ФАЙЛОВ:
- N

КРАТКО ВЫПОЛНЕНО:
- действие

ПЕРЕИМЕНОВАНО / ПЕРЕМЕЩЕНО / УДАЛЕНО:
- отсутствует / краткий список

ПРОВЕРКИ:
- проверка и результат

СУБАГЕНТЫ:
- не использовались / исполнитель, scope и результат

GIT И ВНЕШНИЙ ДОСТУП:
- фактически выполненные разрешённые действия / не использовались
- Commit: нет
- Push: нет

ПРОБЛЕМЫ:
- отсутствуют / краткий список
```

После отчёта Агент пишет одну итоговую строку: `Задача выполнена.`, `Задача частично выполнена.` или `Задача не выполнена.`

Отчёт краткий: он не копирует TASK или изменённые документы и не объявляет результат принятым до REVIEW Ассистента.
