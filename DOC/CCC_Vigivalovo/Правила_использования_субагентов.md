# Правила использования субагентов

Родительская ветвь: `Карта_агентской_документации`.

Дочерний документ: [[Настройка_прав_субагентов]].

## Ответственность

Основной агент задаёт scope, принимает финальное решение, проверяет результат и отвечает перед пользователем. Помощник не расширяет задачу и не получает финальную ответственность.

## Подходящие подзадачи

- read-only инвентаризация и поиск;
- сравнение документов;
- черновая структура;
- проверка Markdown, UTF-8, placeholders и ссылок;
- независимое review ограниченного результата.

Делегирование применимо, когда экономит ресурсы или повышает качество без потери контроля. Финальные инженерные решения, рискованные правки, неограниченный scope и операции Git не делегируются.

## Маршруты

- Локальный профиль `simple_local` может использоваться через управляемый канал субагентов Codex для коротких безопасных задач.
- Внешний агент не указан. Если пользователь выберет его, задача сначала оформляется по форме `Задача_внешнему_субагенту` и передаётся через чат пользователя.
- Основной агент не имитирует внешний запуск и не пишет отчёт от имени внешнего исполнителя.

## Ограничения

- Git запрещён без прямого разрешения.
- Файлы вне scope, `.git`, `.obsidian`, код, ассеты и реальные конфиги агентов не изменяются.
- Субагент не обновляет и не очищает БЛОКИ 1–3 главной TASK; это обязанность основного Агента.
- Результат всегда перепроверяет основной агент.
