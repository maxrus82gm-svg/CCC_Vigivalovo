# Малый блок задачи

[[Старт]] · [[Задача_агенту]] · [[Большой_блок_задачи]]

Отдельное сообщение после размещения большого блока:

```text
Начни активную задачу из DOC/CCC_Vigivalovo/Задача_агенту.md.
Соблюдай указанный scope и политику Git.
По завершении запиши отчёт, выполненные проверки и проблемы.
```

Малый блок не повторяет всю задачу, не расширяет scope и не отменяет Git-политику. Позднее уточнение передаётся отдельным коротким сообщением; при конфликте спорная часть останавливается до решения пользователя.
