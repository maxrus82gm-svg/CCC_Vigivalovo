# Малый блок задачи

Родительский документ: `Большой_блок_задачи`.

## Обязательный стартовый блок

**МАЛЫЙ БЛОК — ЗАПУСК**

Отдельное сообщение после публикации каждой новой большой TASK:

```text
Большая задача опубликована в `M:\GitHub\CCC_Vigivalovo\DOC\CCC_Vigivalovo\Задача_агенту.md`.
Полностью прочитай БЛОК 1 и начинай выполнение в указанном режиме.
Соблюдай канонические правила и ограничения TASK.
По завершении обнови БЛОКИ 1–3 и верни итоговый отчёт.
```

Без этого сообщения опубликованная TASK не считается запущенной.

## Позднее малое уточнение

**МАЛЫЙ БЛОК — УТОЧНЕНИЕ**

```text
Уточнение к активной TASK:

[кратко назвать затронутый пункт и новое указание]

Остальная TASK и её scope остаются без изменений. Если противоречие нельзя разрешить однозначно, останови только спорную часть и зафиксируй проблему.
```

Малое сообщение не переписывает большую TASK и действует только на явно затронутую часть.

## Самостоятельная небольшая задача

**МАЛЫЙ БЛОК — НЕБОЛЬШАЯ ЗАДАЧА**

```text
Самостоятельная небольшая задача:

Цель:
[краткий проверяемый результат]

Разрешённый scope:
[разрешённые файлы и действия]

Ограничения:
[важные запреты, включая Git и внешний доступ]

Проверка:
[как проверить результат]

После выполнения верни краткий отчёт в чат. БЛОКИ 1–3 не изменяй, если это не указано отдельно.
```

Этот блок сам запускает короткую однозначную работу и не требует создания большой TASK. Он не может подменять уточнение уже активной большой TASK.
