## ЖИЗНЕННЫЙ ЦИКЛ

Пользователь → Ассистент → компактная большая TASK → публикация в БЛОКЕ 1 → отдельный малый запуск → локальный Агент → малые уточнения только к затронутым частям → итоговый отчёт в БЛОКЕ 2 → предварительный статус в БЛОКЕ 3 → REVIEW Ассистента → закрытие, уточнение ещё активной частичной TASK либо новая TASK.

После полного выполнения БЛОК 1 очищается. После частичного выполнения или блокировки TASK сохраняется. После очистки любые новые изменения требуют новой, при необходимости очень компактной TASK и нового малого запуска.
