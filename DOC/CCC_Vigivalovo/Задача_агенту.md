## БЛОК 1 — ТЕКУЩАЯ ЗАДАЧА

# ЗАДАЧА — ПРОАНАЛИЗИРОВАТЬ НОВЫЙ UNREAL ENGINE ПРОЕКТ И НАСТРОИТЬ `.gitignore` ДЛЯ МИНИМАЛЬНОГО, НО ИНФОРМАТИВНОГО GITHUB-РЕПОЗИТОРИЯ

## Цель

После создания нового чистого C++ проекта Unreal Engine провести анализ его фактической структуры и настроить `.gitignore` так, чтобы GitHub содержал минимальный объём данных, но при этом через GitHub можно было полноценно анализировать программную архитектуру проекта.

Главный приоритет: через GitHub должны быть доступны все исходники C++ и все текстовые файлы, необходимые для понимания классов, зависимостей, настроек проекта и логики программы.

Тяжёлые графические данные Unreal Engine, сгенерированные файлы, кэши, временные данные, локальные настройки IDE и прочий восстанавливаемый мусор в GitHub загружаться не должны.

Это НЕ задача на создание полностью переносимой копии Unreal-проекта через GitHub.

GitHub в данном проекте используется прежде всего как:

- история исходного кода;
    
- средство контроля изменений;
    
- способ дать ChatGPT доступ к C++ классам и текстовой структуре проекта;
    
- хранилище проектной документации;
    
- средство review.
    

Графические ассеты, `.uasset`, `.umap` и другие тяжёлые бинарные данные могут оставаться только локально, если они не нужны для анализа исходного кода.

При этом НЕ применять слепое правило, если внутри `Content` обнаружены пользовательские текстовые исходники, которые имеют смысл хранить.

Сначала классифицировать фактическое содержимое.
