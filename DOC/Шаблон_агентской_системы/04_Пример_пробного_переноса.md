# Пример пробного переноса

Версия шаблона: **0.3**.

Пробный перенос проверяет логику без создания реального проекта и без изменения этого шаблона.

## Условный паспорт

```text
PROJECT_NAME: Example_Project
PROJECT_ROOT: НЕ УКАЗАНО
OBSIDIAN_VAULT: DOC/Example_Project
DOC_FOLDER: DOC/Example_Project
REPOSITORY_URL: https://github.com/example/example-project.git
REPOSITORY_TYPE: GitHub
DEFAULT_BRANCH: main
MAIN_TASK_FILE: DOC/Example_Project/Задача_агенту.md
EXTERNAL_AGENT_TASK_FILE: DOC/Example_Project/Задача_внешнему_субагенту.md
START_FILE: DOC/Example_Project/Старт.md
PROJECT_TYPE: docs only
BUILD_SYSTEM: НЕ УКАЗАНО
FORBIDDEN_FOLDERS: .git; DOC/Example_Project/.obsidian
USER_GIT_POLICY: только операции чтения по прямой задаче
```

## Проверка

1. Выбрать один шаблонный документ.
2. Сформировать его самостоятельную рабочую версию вне каталога шаблона.
3. Заменить обязательные placeholders значениями условного паспорта.
4. Оставить неизвестное как `НЕ УКАЗАНО`.
5. Убедиться, что рабочая версия не ссылается на шаблон как на правило.
6. Удалить пробный результат после проверки; реальные проекты и Git не менять.

Пробный перенос успешен, если можно однозначно перечислить подстановки, неизвестные значения и проверки, а исходный шаблон остался неизменным.
