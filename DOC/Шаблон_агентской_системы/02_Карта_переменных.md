# Карта переменных

Версия шаблона: **0.4**.

Все placeholders записываются как `{{VARIABLE_NAME}}` и сохраняются в универсальном шаблоне.

| Переменная | Назначение | Пример | Обязательность |
|---|---|---|---|
| `{{PROJECT_NAME}}` | Название проекта | `Example_Project` | обязательно |
| `{{PROJECT_ROOT}}` | Корень проекта | `НЕ УКАЗАНО` или проверенный путь | обязательно |
| `{{OBSIDIAN_VAULT}}` | Рабочий Vault | `DOC/Example_Project` | обязательно |
| `{{DOC_FOLDER}}` | Папка документов | `DOC/Example_Project` | обязательно |
| `{{REPOSITORY_URL}}` | URL репозитория | `https://github.com/owner/repo.git` | если есть Git |
| `{{REPOSITORY_TYPE}}` | Тип репозитория | `GitHub` | необязательно |
| `{{DEFAULT_BRANCH}}` | Основная ветка | `main` | если есть Git |
| `{{MAIN_TASK_FILE}}` | Активная задача | `{{DOC_FOLDER}}/Задача_агенту.md` | обязательно |
| `{{EXTERNAL_AGENT_TASK_FILE}}` | Задача внешнему агенту | `{{DOC_FOLDER}}/Задача_внешнему_субагенту.md` | по необходимости |
| `{{START_FILE}}` | Центральная карта | `{{DOC_FOLDER}}/Старт.md` | обязательно |
| `{{AGENT_DOC_MAP_FILE}}` | Тематическая карта агентской системы | `{{DOC_FOLDER}}/Карта_агентской_документации.md` | обязательно |
| `{{AGENT_CYCLE_RULES_FILE}}` | Правила ролей и жизненного цикла | `{{DOC_FOLDER}}/Правила_агентского_цикла.md` | обязательно |
| `{{TASK_LAUNCH_RULES_FILE}}` | Правила публикации и запуска TASK | `{{DOC_FOLDER}}/Правила_запуска_задач.md` | обязательно |
| `{{RULES_FOLDER}}` | Папка правил | `{{DOC_FOLDER}}` | обязательно |
| `{{DEFAULT_AGENT_MODE}}` | Режим при отсутствии явного указания | `Самостоятельный` | обязательно |
| `{{PROJECT_TYPE}}` | Тип проекта | `C++ game` | необязательно |
| `{{BUILD_SYSTEM}}` | Система сборки | `CMake` | необязательно |
| `{{CODE_FOLDERS}}` | Исходный код | `src; include` | необязательно |
| `{{ASSET_FOLDERS}}` | Ассеты | `assets` | необязательно |
| `{{CONFIG_FOLDERS}}` | Конфиги | `config` | необязательно |
| `{{FORBIDDEN_FOLDERS}}` | Запрещённые области | `.git; .obsidian` | обязательно |
| `{{AGENT_CONFIG_PATHS}}` | Реальные конфиги агентов | `НЕ УКАЗАНО` | необязательно |
| `{{SUBAGENT_PROFILES}}` | Профили субагентов | `НЕ УКАЗАНО` | необязательно |
| `{{MAIN_AGENT_NAME}}` | Основной агент | `основной агент` | обязательно |
| `{{LOCAL_AGENT_NAME}}` | Локальный агент | `локальный помощник` | необязательно |
| `{{EXTERNAL_AGENT_NAME}}` | Внешний агент | `внешний агент` | необязательно |
| `{{LOCAL_AGENT_ROUTE}}` | Локальный маршрут | `управляемый канал` | необязательно |
| `{{EXTERNAL_AGENT_ROUTE}}` | Внешний маршрут | `чат пользователя` | необязательно |
| `{{SERVICE_FOLDERS}}` | Служебные папки | `.git; .obsidian` | необязательно |
| `{{IDE_SERVICE_FILES}}` | Файлы IDE | `workspace.json` | необязательно |
| `{{CURRENT_BASE_COMMIT}}` | Проверенный SHA | полный SHA или `НЕ УКАЗАНО` | необязательно |
| `{{USER_GIT_POLICY}}` | Политика Git | `только чтение` | обязательно |

В рабочем документе обязательные placeholders заменяются. Если значение определить нельзя, записывается `НЕ УКАЗАНО` и причина попадает в отчёт.
