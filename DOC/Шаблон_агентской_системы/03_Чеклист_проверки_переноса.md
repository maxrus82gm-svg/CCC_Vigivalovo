# Чеклист проверки переноса

Версия шаблона: **0.3**.

## Разделение

- [ ] Шаблон остался отдельным источником-примером.
- [ ] Каталог шаблона не копировался в рабочий Vault.
- [ ] Рабочие документы самостоятельны и не ссылаются на шаблон как на правило.
- [ ] Автоматическая синхронизация между шаблоном и проектом отсутствует.

## Структура и дубли

- [ ] Фактические имена совпадают с [[Манифест_структуры]].
- [ ] Каждый документ имеет одно назначение.
- [ ] Каждое правило имеет одного канонического владельца.
- [ ] Маршрутизаторы содержат ссылки и краткие резюме, а не полные копии.
- [ ] Нет русского и английского дубля одного документа.

## Значения и свойства

- [ ] В шаблоне placeholders сохранены.
- [ ] В рабочих документах обязательные placeholders заменены.
- [ ] Неизвестные значения обозначены `НЕ УКАЗАНО` и перечислены в отчёте.
- [ ] Frontmatter согласован, не содержит дублей свойств и корректно обозначает статус.

## Obsidian

- [ ] Центральная карта связывает все рабочие документы напрямую или за один переход.
- [ ] Каждый рабочий документ ссылается на центральную карту.
- [ ] Wiki-links разрешаются и не содержат самоссылок.
- [ ] Рабочая Base существует в одном экземпляре и отбирает только рабочие документы.
- [ ] `.obsidian` не изменялась без прямого разрешения.

## Кодировка

- [ ] Все изменённые Markdown-файлы читаются как UTF-8.
- [ ] Кириллица и кириллические имена файлов сохранены.
- [ ] Использованы настоящие переносы строк.
- [ ] Нет буквальной последовательности `\n` вместо переноса.

## Git и отчёт

- [ ] Свежие SHA, message и список файлов коммита получены напрямую из удалённого репозитория, если это требует задача.
- [ ] Git использовался только в разрешённом режиме.
- [ ] Commit, push, pull, fetch и изменение ветки не выполнялись без прямой команды.
- [ ] Итоговый отчёт записан.
