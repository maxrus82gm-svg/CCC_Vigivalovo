## Правила заполнения

1. Использовать проверенные значения проекта и относительные пути репозитория, когда это возможно.
2. Не выдумывать абсолютные пути, конфиги, профили и репозитории.
3. Для неизвестного значения использовать `НЕ УКАЗАНО`.
4. Перечислить неизвестные значения в итоговом отчёте.
