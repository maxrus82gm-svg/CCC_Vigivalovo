# Малый блок задачи

[[Старт]] · [[Задача_агенту]] · [[Большой_блок_задачи]]

Форма ниже отправляется отдельным цельным сообщением после размещения большого блока.

```text
Начни активную задачу из {{MAIN_TASK_FILE}}.
Соблюдай указанный scope и политику Git.
Позднее уточнение: {{LATE_CLARIFICATION}}
По завершении запиши отчёт и явно перечисли проверки и проблемы.
```

Если позднего уточнения нет, строка с ним удаляется в рабочем сообщении. Малый блок не повторяет всю задачу, не расширяет scope и не противоречит большому блоку.
