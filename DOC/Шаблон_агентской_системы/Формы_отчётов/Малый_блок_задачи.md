# Малый блок задачи

Родительский документ: `Большой_блок_задачи`.

## Обязательный стартовый блок

**МАЛЫЙ БЛОК — ЗАПУСК**

```text
Большая задача опубликована в `{{MAIN_TASK_FILE}}`.
Полностью прочитай БЛОК 1 и начинай выполнение в указанном режиме.
Соблюдай канонические правила и ограничения TASK.
По завершении обнови БЛОКИ 1–3 и верни итоговый отчёт.
```

Без этого сообщения опубликованная TASK ещё не запущена.

## Позднее уточнение

**МАЛЫЙ БЛОК — УТОЧНЕНИЕ**

```text
Уточнение к активной TASK:

{{LATE_CLARIFICATION}}

Остальная TASK и её scope остаются без изменений. Неразрешимый конфликт останавливает только спорную часть.
```

## Самостоятельная небольшая задача

**МАЛЫЙ БЛОК — НЕБОЛЬШАЯ ЗАДАЧА**

```text
Самостоятельная небольшая задача:

Цель:
{{SMALL_TASK_GOAL}}

Разрешённый scope:
{{SMALL_TASK_SCOPE}}

Ограничения:
{{SMALL_TASK_RESTRICTIONS}}

Проверка:
{{SMALL_TASK_CHECK}}

После выполнения верни краткий отчёт в чат. БЛОКИ 1–3 не изменяй, если это не указано отдельно.
```

Самостоятельный малый блок сам запускает короткую работу и не подменяет уточнение активной большой TASK.
