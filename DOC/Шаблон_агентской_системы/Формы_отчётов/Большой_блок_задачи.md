# Большой блок задачи

Родительский документ: `Правила_запуска_задач`.

Служебная подпись находится снаружи и не входит в копируемый текст. После неё компактная форма уникальной работы выдаётся одним непрерывным кодовым блоком. Постоянные правила не копируются.

**БЛОК 1 — БОЛЬШАЯ ЗАДАЧА**

```text
# ЗАДАЧА — {{TASK_TITLE}}

Режим: Ограниченный / Самостоятельный

## Цель

{{TASK_GOAL}}

## Специфический контекст

{{TASK_CONTEXT}}

## Разрешённый scope

{{ALLOWED_SCOPE}}

## Нестандартные запреты и особые разрешения

{{FORBIDDEN_SCOPE}}

## Обязательные проверки

{{REQUIRED_CHECKS}}

## Критерии готовности

{{DONE_CRITERIA}}

## Дополнения к стандартному отчёту

{{REPORT_FORMAT}}

## Применяемые канонические правила

{{TASK_RULE_LINKS}}
```

После публикации TASK замораживается и запускается по форме [[Малый_блок_задачи|малого стартового блока]].
