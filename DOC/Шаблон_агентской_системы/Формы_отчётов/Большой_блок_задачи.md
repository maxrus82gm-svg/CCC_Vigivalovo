# Большой блок задачи

[[Карта_агентской_документации]] · [[Правила_запуска_задач]] · [[Малый_блок_задачи]]

Компактная форма уникальной работы выдаётся одним непрерывным кодовым блоком. Постоянные правила не копируются.

```text
# ЗАДАЧА — {{TASK_TITLE}}

Режим: Ограниченный / Самостоятельный

## Цель

{{TASK_GOAL}}

## Специфический контекст

{{TASK_CONTEXT}}

## Разрешённый scope

{{ALLOWED_SCOPE}}

## Нестандартные запреты и особые разрешения

{{FORBIDDEN_SCOPE}}

## Обязательные проверки

{{REQUIRED_CHECKS}}

## Критерии готовности

{{DONE_CRITERIA}}

## Дополнения к стандартному отчёту

{{REPORT_FORMAT}}

## Применяемые канонические правила

{{TASK_RULE_LINKS}}
```

После публикации TASK замораживается и запускается отдельным малым стартовым блоком.
