# Отчёт агента

Родительский документ: `Правила_агентского_цикла`.

Единый стандартный формат отчёта. TASK добавляет только действительно необходимые специальные поля.

```text
ОТЧЁТ АГЕНТА

TASK:
- название

РЕЖИМ:
- Ограниченный / Самостоятельный

СТЕПЕНЬ ВЫПОЛНЕНИЯ:
- выполнено полностью / выполнено частично / не выполнено

ИЗМЕНЕНО ФАЙЛОВ:
- N

КРАТКО ВЫПОЛНЕНО:
- действие

ПЕРЕИМЕНОВАНО / ПЕРЕМЕЩЕНО / УДАЛЕНО:
- отсутствует / краткий список

ПРОВЕРКИ:
- проверка и результат

СУБАГЕНТЫ:
- не использовались / исполнитель, scope и результат

GIT И ВНЕШНИЙ ДОСТУП:
- фактические разрешённые действия / не использовались
- Commit: нет
- Push: нет

ПРОБЛЕМЫ:
- отсутствуют / краткий список
```

После отчёта — одна строка: `Задача выполнена.`, `Задача частично выполнена.` или `Задача не выполнена.`
