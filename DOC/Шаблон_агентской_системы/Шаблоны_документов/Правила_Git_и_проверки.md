## Владелец и разрешения

Git полностью контролирует пользователь. Если задача не разрешает Git, агент не выполняет даже команды чтения.

Обязательная read-only проверка удалённого репозитория Ассистентом после отчёта не разрешает Агенту локальные Git-команды или удалённые изменения.

При прямом разрешении на чтение допустимы: `git status`, `git log`, `git show`, `git diff`, `git branch --show-current` и чтение GitHub через API или коннектор.

Без отдельной прямой команды запрещены: commit, push, pull, fetch, merge, rebase, reset, clean, checkout, switch, создание или удаление веток и тегов, изменение remote, Git-конфига и истории.

## Обязательная проверка после отчёта

После получения итогового отчёта Агента Ассистент сначала проверяет актуальное удалённое состояние, если задача относится к текущему проекту и репозиторий доступен. Только затем анализируется отчёт и выполняется REVIEW.

Порядок проверки:

1. Получить актуальную ветку непосредственно из GitHub.
2. Получить последний commit по актуальному ref.
3. Зафиксировать полный SHA и фактический message без исправлений.
4. Получить список файлов этого commit.
5. Читать важные удалённые файлы по зафиксированному SHA или актуальному ref.
6. Не использовать старый скриншот, открытую страницу, кэш или прежний результат.
7. Если ожидаемый commit отсутствует, писать `push не обнаружен`.
8. Если GitHub недоступен, писать `удалённый commit не подтверждён`.
9. Для Issue или Pull Request заново получить комментарии и не считать старую копию актуальной.
10. В отчёте указать фактически прочитанные SHA и message.

После успешной проверки ответ начинается с:

```text
СТАТУС КОММИТА
GIT / ПРОВЕРКА РЕПОЗИТОРИЯ
Последний удалённый commit прочитан: <SHA> — <message>
```

Если изменения Агента существуют только локально и ещё не прошли Commit/Push, Ассистент прямо пишет, что последний удалённый commit проверен, но новые локальные изменения на GitHub пока не подтверждены.

Нельзя утверждать, что изменения находятся на GitHub, если подтверждено только их локальное наличие.

## REVIEW Ассистента

Отчёт Агента запускает REVIEW, но не заменяет фактическую проверку. GitHub используется только по разрешённой политике проекта. Непроверенная область обозначается явно.

Формат находится в [[Отчёт_проверки]]. Ответ начинается с:

```text
СТАТУС КОММИТА
GIT / ПРОВЕРКА РЕПОЗИТОРИЯ
```

Служебные изменения вне scope перечисляются как неожиданные. Решение после REVIEW принимается по [[Правила_агентского_цикла]].
