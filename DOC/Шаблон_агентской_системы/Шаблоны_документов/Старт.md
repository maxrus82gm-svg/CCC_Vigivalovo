## Обязательное чтение Агента

1. Этот документ.
2. Через `Карта_агентской_документации` открыть правила агентского цикла и запуска задач.
3. Для большого цикла прочитать `Задача_агенту`; для самостоятельной небольшой задачи — полученный малый блок.
4. Прочитать только тематические правила, необходимые текущей работе.

## Границы

- Git контролирует пользователь; подробности находятся в правилах Git и проверки.
- `.obsidian` и реальные конфиги агентов не меняются без прямого разрешения.
- Рабочие документы самостоятельны и не используют каталог универсального шаблона как источник действующих правил.
- Граф строится по иерархии: `Старт` → [[Карта_агентской_документации]] → каноническое правило → дочерний документ.

> В рабочей версии заменить все обязательные placeholders. Неизвестное значение обозначить `НЕ УКАЗАНО`.
