## Границы

- Git контролирует пользователь; подробности — в [[Правила_Git_и_проверки]].

- Рабочие документы самостоятельны и не используют каталог универсального шаблона как источник действующих правил.
- Граф строится по иерархии: `Старт` → [[Карта_агентской_документации]] → рабочий документ.
