# Правила локальной работы агента

Родительская ветвь: `Карта_агентской_документации`.

## Режим по умолчанию

Агент и локальные субагенты работают только с локальными файлами, каталогами, процессами и инструментами проекта `{{PROJECT_NAME}}`.

Агент выполняет только текущую поставленную работу — активную большую TASK либо самостоятельный малый блок, — изменяет только явно разрешённые файлы, сохраняет существующие изменения Пользователя, не создаёт лишних файлов и не расширяет архитектуру или scope самостоятельно.

Без чёткого прямого разрешения Пользователя запрещено:

- обращаться к интернету, внешним API и облачным сервисам;
- использовать коннекторы, почту и мессенджеры;
- читать или изменять удалённые репозитории;
- передавать локальные файлы или сведения о проекте во внешние системы;
- запускать внешнего агента.

Наличие URL, сетевого инструмента, подключения или авторизации не является разрешением.

## Прямое разрешение

Разрешение действует только для названного ресурса, действия и текущей TASK. После него режим снова считается локальным.

Если [[Правила_Git_и_проверки]] проекта закрепляют обязательную read-only проверку доступного удалённого репозитория после отчёта, она считается отдельным постоянным разрешением только для REVIEW Ассистента. Локальный Агент не получает из этого разрешения на сеть, Git-команды или удалённые изменения.

Git дополнительно ограничен [[Правила_Git_и_проверки]]. Возможности среды не расширяют scope, разрешения на служебные каталоги, код, ассеты или конфигурацию.
