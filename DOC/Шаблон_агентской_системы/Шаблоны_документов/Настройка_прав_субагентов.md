## Проверка перед запуском

- Среда действительно может читать проект и нужные документы.
- Запись разрешена только в явный scope.
- Требуемые tools доступны.
- Ограничения sandbox и подтверждения пользователя понятны.
- Git и служебные области не становятся доступными только из-за возможностей модели.

Реальные конфиги и permissions не меняются без прямой задачи пользователя.

При отсутствии доступа отчёт содержит исполнителя, маршрут, недостающее разрешение или инструмент, запрошенный путь и фактический результат.
