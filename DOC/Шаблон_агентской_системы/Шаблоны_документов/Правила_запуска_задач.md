# Правила запуска задач

Родительская ветвь: `Карта_агентской_документации`.

## Назначение

Канонический владелец выбора формы задачи, публикации большой TASK, обязательного малого запуска, самостоятельных малых задач, поздних уточнений, внешних подписей блоков и обновления БЛОКОВ 1–3.

## Дочерние документы

- [[Задача_агенту]] — активная большая TASK, последний отчёт и последний REVIEW / статус.
- [[Большой_блок_задачи]] — форма большой TASK; из неё открывается форма малого блока.

## Выбор формы задачи

Не каждая работа требует большой TASK. Ассистент выбирает форму по масштабу и необходимости сохранять постановку до итогового отчёта.

Большая TASK нужна для заметного или многоэтапного scope, длительного цикла, фиксации в БЛОКЕ 1, важных ограничений и проверок либо неизменного сохранения постановки.

Короткая, однозначная и легко проверяемая работа передаётся самостоятельным малым блоком прямо в чат Агента, если отдельная большая TASK добавит больше бюрократии, чем пользы.

Самостоятельный малый блок не обходит активную большую TASK. Сообщение, относящееся к активной TASK, является её запуском или уточнением.

## Внешняя подпись copy-paste блока

Ассистент всегда ставит служебную подпись типа **снаружи** цельного copy-paste блока. Подпись не входит в копируемый текст.

- `БЛОК 1 — БОЛЬШАЯ ЗАДАЧА`;
- `МАЛЫЙ БЛОК — ЗАПУСК`;
- `МАЛЫЙ БЛОК — УТОЧНЕНИЕ`;
- `МАЛЫЙ БЛОК — НЕБОЛЬШАЯ ЗАДАЧА`.

## Большой цикл: два обязательных сообщения

Для нового большого цикла Ассистент готовит отдельно:

1. большую TASK для БЛОКА 1;
2. малый стартовый блок для чата Агента.

Без малого стартового блока опубликованная TASK ещё не запущена.

## Компактная большая TASK

TASK содержит уникальные цель, контекст, режим, scope, нестандартные запреты и разрешения, специальные проверки, критерии готовности и дополнения к отчёту.

Постоянные роли, жизненный цикл, Git, локальный режим, UTF-8, документация, субагенты и стандартный отчёт не копируются полностью; TASK ссылается на канонических владельцев.

После публикации TASK замораживается.

## Малые сообщения

Стартовый блок сообщает о публикации, указывает `{{MAIN_TASK_FILE}}`, запускает выполнение и требует отчёт.

Все относящиеся к активной большой TASK уточнения до отчёта передаются отдельными малыми сообщениями. Уточнение действует только на явно затронутую часть и не меняет остальной scope.

Самостоятельная небольшая задача содержит цель, scope, ограничения, проверку и требование краткого отчёта. Она сама запускает работу, не создаёт большую TASK и не меняет БЛОКИ 1–3, если Пользователь не указал иное.

## Обновление БЛОКОВ

Главный документ разделяет области едиными линиями и цветными маркерами:

- `🟦 БЛОК 1` — активная TASK;
- `🟩 БЛОК 2` — последний отчёт;
- `🟨 БЛОК 3` — REVIEW / статус.

Оформление не требует CSS, изменения `.obsidian` или управления координатами графа.

В большом цикле при полном выполнении Агент:

1. заменяет БЛОК 2 последним отчётом;
2. заменяет БЛОК 3 последним предварительным статусом;
3. очищает TASK из БЛОКА 1 и оставляет:

```text
Активная задача отсутствует.

Статус: ожидается новая задача от Пользователя.
```

При частичном выполнении или блокировке БЛОК 1 сохраняется. Главный документ хранит только активную TASK, последний отчёт и последний REVIEW / статус, а не архив.
