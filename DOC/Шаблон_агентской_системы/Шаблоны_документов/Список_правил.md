# Список правил

Этот документ — дочерняя служебная матрица `Карты агентской документации`. Полные формулировки хранятся у канонических владельцев; повторный набор wiki-связей здесь намеренно не создаётся.

| Область | Канонический документ |
|---|---|
| Роли, режимы, заморозка TASK, жизненный цикл и REVIEW | `Правила_агентского_цикла` |
| Выбор большой или малой задачи, внешние подписи блоков, запуск, уточнения и БЛОКИ 1–3 | `Правила_запуска_задач` |
| Git, обязательная удалённая проверка после отчёта, SHA и REVIEW | `Правила_Git_и_проверки` |
| Локальный режим и разрешение на внешний доступ | `Правила_локальной_работы_агента` |
| Markdown, UTF-8, кириллица, frontmatter и wiki-links | `Правила_создания_документов` |
| Делегирование и контроль субагентов | `Правила_использования_субагентов` |
| Разрешения и маршруты субагентов | `Настройка_прав_субагентов` |
| Активная TASK, последний отчёт и последний статус | `Задача_агенту` |
| Задача внешнему агенту | `Задача_внешнему_субагенту` |
| Форматы отчётов | `Отчёт_агента`, `Отчёт_субагента`, `Отчёт_проверки` |

Обязательный минимум определён в `Старт`. Переход к владельцам выполняется через `Карта_агентской_документации`.
