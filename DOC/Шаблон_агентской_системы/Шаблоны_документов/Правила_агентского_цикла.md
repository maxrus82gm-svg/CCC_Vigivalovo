# Правила агентского цикла

[[Карта_агентской_документации]] · [[Задача_агенту]] · [[Правила_запуска_задач]] · [[Отчёт_агента]]

## Назначение

Канонический владелец ролей, режимов, заморозки опубликованной TASK, жизненного цикла и REVIEW Ассистента.

Git-политика, локальная работа, запуск TASK и формат отчёта остаются у своих канонических владельцев и здесь не дублируются.

## Роли

### Пользователь

- принимает конечные и архитектурные решения;
- управляет Git и опасными операциями;
- публикует TASK и отправляет малый запуск;
- передаёт отчёт Агента Ассистенту и подтверждает новый цикл.

### Ассистент ChatGPT

- создаёт компактную большую TASK и отдельный обязательный малый запуск;
- до отчёта передаёт изменения только малыми уточнениями;
- после отчёта выполняет REVIEW;
- формирует следующую большую TASK только после решения по предыдущему циклу.

### Локальный Агент

- читает активную TASK и канонические правила;
- выполняет только разрешённый scope;
- применяет уточнение только к затронутой части;
- записывает отчёт и предварительный статус;
- не объявляет результат принятым.

### Субагенты

Работают только внутри делегированного scope. Основной Агент перепроверяет результат и отвечает перед Пользователем.

## Режимы

- `Ограниченный` — реализация и границы заданы; неоднозначная часть останавливается.
- `Самостоятельный` — Агент выбирает безопасный способ внутри заданной цели, архитектуры и scope.

Если режим не указан, применяется самостоятельный режим без права расширять scope или постоянные правила.

## Замороженная TASK

После публикации и до итогового отчёта БЛОК 1 заморожен. TASK нельзя переписывать, заменять или редактировать из-за уточнений.

Уточнения передаются отдельными малыми сообщениями. Позднее явное уточнение имеет приоритет только для затронутой части. Неразрешимый конфликт останавливает только спорную часть.

## Жизненный цикл

1. Ассистент создаёт большую TASK и малый запуск.
2. Пользователь публикует TASK в БЛОКЕ 1 и отправляет малый запуск Агенту.
3. Агент выполняет работу; уточнения приходят только малыми сообщениями.
4. Агент обновляет БЛОКИ 2–3 и при полном выполнении очищает содержимое БЛОКА 1.
5. Пользователь передаёт отчёт Ассистенту и самостоятельно управляет Git.
6. Ассистент выполняет REVIEW и рекомендует закрытие, уточнение ещё активной частичной TASK, новую TASK или откат Пользователем.

Отчёт завершает локальный этап, но не означает принятие результата. Завершённая TASK задним числом не переписывается. После очистки БЛОКА 1 новые изменения требуют новой, при необходимости очень компактной TASK и нового малого запуска.

## Постоянные правила

Постоянные правила меняются только по отдельной TASK, основанной на решении Пользователя.
